# Dependencies

This mod targets the Hearth & Horizons modpack and requires its culinary mods. Install the NeoForge 1.21.1 versions and their own dependencies on both client and server.

JEI is optional. Exact supported API ranges are declared in `src/main/resources/META-INF/neoforge.mods.toml`; build dependency hashes are in `dependency-lock.json`.

Croptopia 4.2.1 and MineColonies 1.1.1300 are external dependencies in the tested pack.
